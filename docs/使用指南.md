## 安装与配置

### 步骤 1: 安装依赖

```bash
# 进入项目目录
cd adaptive_agent_mcp

# 使用 pip 安装
pip install -e .

# 或使用 uv (更快)
uv pip install -e .
```

### 步骤 2: 安装 Ripgrep (可选但推荐)

Ripgrep 用于全文搜索功能，强烈推荐安装：

**Windows:**
```powershell
# 使用 Chocolatey
choco install ripgrep

# 或使用 Scoop
scoop install ripgrep

# 或手动下载
# https://github.com/BurntSushi/ripgrep/releases
```

**macOS:**
```bash
brew install ripgrep
```

**Linux:**
```bash
# Ubuntu/Debian
sudo apt install ripgrep

# Fedora
sudo dnf install ripgrep

# Arch
sudo pacman -S ripgrep
```

### 步骤 3: 配置 MCP 客户端

#### 选项 A: VS Code / Cline / Roo Code

1. 在项目根目录创建 `.kiro/settings/mcp.json` 或 `.vscode/mcp.json`
2. 复制以下配置：

```json
{
  "mcpServers": {
    "adaptive-agent-mcp": {
      "command": "python",
      "args": [
        "${workspaceFolder}/adaptive_agent_mcp/server.py",
        "--storage-path",
        "${workspaceFolder}/agent_memory"
      ],
      "disabled": false,
      "autoApprove": [
        "initialize_session",
        "query_memory_headers"
      ]
    }
  }
}
```

3. 重启 VS Code 或重新加载窗口

#### 选项 B: Claude Desktop

1. 找到配置文件位置：
   - Windows: `%APPDATA%\Claude\claude_desktop_config.json`
   - macOS: `~/Library/Application Support/Claude/claude_desktop_config.json`
   - Linux: `~/.config/Claude/claude_desktop_config.json`

2. 编辑配置文件（使用绝对路径）：

```json
{
  "mcpServers": {
    "adaptive-memory": {
      "command": "python",
      "args": [
        "C:/Users/YourName/Projects/adaptive_agent_mcp/server.py",
        "--storage-path",
        "C:/Users/YourName/Documents/AgentMemory"
      ]
    }
  }
}
```

3. 重启 Claude Desktop

### 步骤 4: 验证安装

在 AI 对话中输入：

```
请调用 initialize_session 工具
```

如果返回类似以下内容，说明配置成功：

```
# Session Initialized
**System Time**: 2026-02-05

## [User Profile & Implicit Knowledge]
---
type: implicit_knowledge
...
```

## 基础使用

### 1. 会话初始化

**每次对话开始时，Agent 应该首先调用此工具**

```python
initialize_session()
```

**返回内容**:
- 当前系统时间
- 用户画像 (MEMORY.md)
- 最近 2 天的完整日志
- 本周的活动摘要

**用户视角**:
```
User: 你好，我们继续昨天的工作

Agent: (自动调用 initialize_session)
你好！我已经加载了记忆。昨天我们在开发用户认证模块...
```

### 2. 记录日常活动

**场景**: 记录任务进度、想法、笔记

```python
append_daily_log(
    content="完成了用户注册功能的开发，包括邮箱验证",
    tags=["development", "auth", "backend"]
)
```

**用户视角**:
```
User: 我刚完成了用户注册功能

Agent: 很好！我已经记录到今天的日志中了 ✅
(调用 append_daily_log)
```

### 3. 保存知识

**场景**: 记录技术约束、领域知识、最佳实践

```python
append_daily_log(
    atomic_fact={
        "fact": "项目使用 JWT 进行身份认证，token 有效期 24 小时",
        "category": "domain_knowledge",
        "tags": ["auth", "jwt", "security"]
    }
)
```

**用户视角**:
```
User: 记住，我们的 JWT token 有效期是 24 小时

Agent: 已保存到知识库 ✅
(调用 append_daily_log with atomic_fact)
```

### 4. 记录用户偏好

**场景**: 保存用户的个人偏好和习惯

```python
append_daily_log(
    atomic_fact={
        "fact": "用户喜欢使用 Tailwind CSS 而不是 Bootstrap",
        "category": "user_preference"
    }
)
```

**用户视角**:
```
User: 以后都用 Tailwind CSS，我不喜欢 Bootstrap

Agent: 明白了，已更新你的偏好设置 ✅
(调用 append_daily_log with category="user_preference")
```

### 5. 查询历史记忆

**场景**: 用户想回忆之前的讨论或决策

**步骤 1: 扫描索引**
```python
query_memory_headers(tags=["database", "design"])
```

**步骤 2: 读取具体内容**
```python
read_memory_content([
    "agent_memory/memory/2026/01_january/week_04/2026-01-28.md"
])
```

**用户视角**:
```
User: 我们之前讨论过数据库设计吗？

Agent: 
(调用 query_memory_headers)
是的，在 1 月 28 日我们讨论了用户表的设计...
(调用 read_memory_content 读取详细内容)
```

### 6. 全文搜索

**场景**: 记不清具体日期，只记得关键词

```python
search_memory_content(query="CSRF token", regex=False)
```

**用户视角**:
```
User: 我记得我们解决过一个 CSRF 的问题

Agent:
(调用 search_memory_content)
找到了！在 2 月 3 日，你修复了登录页面的 CSRF token 过期问题...
```

## 高级功能

### 知识演化 (Knowledge Evolution)

当需求变化时，使用 supersede 机制更新知识：

```python
# 第一次：记录初始决策
append_daily_log(
    atomic_fact={
        "id": "db-choice-001",
        "fact": "项目使用 MySQL 数据库",
        "category": "domain_knowledge"
    }
)

# 后来：需求变更
append_daily_log(
    atomic_fact={
        "id": "db-choice-002",
        "fact": "项目改用 PostgreSQL 数据库",
        "category": "domain_knowledge",
        "supersedes_id": "db-choice-001"
    }
)
```

**结果**:
- `db-choice-001` 被标记为 `"status": "superseded"`
- `db-choice-002` 成为 `"status": "active"`
- 保留完整的决策历史

### 周期总结

**生成周总结**:

```python
# 步骤 1: 获取本周所有日志
context = get_period_context(period="week")

# 步骤 2: Agent 阅读并生成总结
summary = """
# 本周工作总结 (2026-02-03 至 2026-02-09)

## 主要成果
- 完成用户认证模块 (登录、注册、密码重置)
- 修复 3 个安全漏洞
- 编写 15 个单元测试

## 技术决策
- 采用 JWT 认证方案
- 使用 bcrypt 加密密码

## 下周计划
- 开发用户权限管理
- 集成第三方登录 (Google, GitHub)
"""

# 步骤 3: 保存总结
archive_period(summary_content=summary, period="week")
```

**用户视角**:
```
User: 帮我生成本周的工作总结

Agent:
(调用 get_period_context)
(生成总结)
(调用 archive_period)

这是本周的工作总结：
[显示总结内容]
已保存到 week_summary.md ✅
```

## 最佳实践

### 1. 标签策略

**推荐的标签分类**:

```
# 按领域
- frontend, backend, database, devops
- ui, api, auth, payment

# 按类型
- bug-fix, feature, refactor, docs
- meeting, decision, idea

# 按项目
- project-alpha, project-beta
- client-acme, internal

# 按优先级
- urgent, important, nice-to-have
```

**示例**:
```python
append_daily_log(
    content="修复了支付模块的并发问题",
    tags=["backend", "payment", "bug-fix", "urgent"]
)
```

### 2. 内容组织

**每日笔记的推荐格式**:

```markdown
---
type: daily_log
date: "2026-02-05"
tags: ["development", "backend"]
summary: "完成支付模块开发和测试"
---

### 09:00 - 开始工作
今天的目标：完成支付模块的集成测试

### 10:30 - 遇到问题
发现 Stripe API 的 webhook 验证失败
错误信息: "Invalid signature"

### 11:15 - 解决方案
原因是 webhook secret 配置错误
已更新环境变量并重新部署

### 14:00 - 完成测试
所有测试用例通过 ✅
- 单元测试: 25/25
- 集成测试: 8/8

### 16:00 - 代码审查
提交 PR #123，等待审查
```

### 3. 知识分类

**domain_knowledge (领域知识)**:
- 技术约束
- 架构决策
- API 规范
- 最佳实践

**user_preference (用户偏好)**:
- 编码风格
- 工具选择
- 沟通方式
- 工作习惯

### 4. 查询策略

**优先使用结构化查询**:
```python
# ✅ 好的做法
query_memory_headers(tags=["auth"])  # 快速，精确

# 备选方案
search_memory_content(query="authentication")  # 较慢，但更灵活
```

**组合使用**:
```python
# 1. 先用索引定位范围
headers = query_memory_headers(tags=["database"])

# 2. 再读取具体内容
content = read_memory_content([path1, path2])

# 3. 如果还没找到，使用全文搜索
results = search_memory_content(query="migration script")
```

## 常见问题

### Q1: 记忆文件存储在哪里？

**A**: 由 `--storage-path` 参数指定。推荐配置：

- **开发环境**: `${workspaceFolder}/agent_memory` (项目内)
- **生产环境**: `~/.adaptive-agent/memory` (全局)
- **多项目**: 每个项目使用独立路径

### Q2: 如何备份记忆？

**A**: 记忆文件都是纯文本 (Markdown + JSON)，可以直接：

```bash
# 备份
cp -r agent_memory agent_memory_backup_2026-02-05

# 或使用 Git
cd agent_memory
git init
git add .
git commit -m "Memory snapshot 2026-02-05"
```

### Q3: 可以手动编辑记忆文件吗？

**A**: 可以！所有文件都是人类可读的格式：

- 每日笔记: Markdown
- 知识图谱: JSON
- 用户画像: Markdown with YAML

编辑后，索引会在下次 `append_daily_log` 时自动更新。

### Q4: 如何删除旧的记忆？

**A**: 直接删除文件即可：

```bash
# 删除某一天的日志
rm agent_memory/memory/2026/01_january/week_01/2026-01-05.md

# 删除整个月
rm -rf agent_memory/memory/2026/01_january

# 重建索引
# (下次调用任何工具时会自动重建)
```

### Q5: 支持多个 Agent 共享记忆吗？

**A**: 支持，但需要注意：

- **读取**: 完全安全，多个 Agent 可以同时读取
- **写入**: 可能有并发冲突，建议使用文件锁或队列

### Q6: 记忆文件会占用多少空间？

**A**: 取决于使用频率：

- 每日笔记: 约 1-5 KB/天
- 知识图谱: 约 10-50 KB (累积)
- 索引缓存: 约 1-10 KB

**估算**: 一年约 2-5 MB (轻度使用) 到 50-100 MB (重度使用)

## 故障排查

### 问题 1: 工具调用失败

**症状**: Agent 说"无法调用工具"或"工具不存在"

**排查步骤**:

1. 检查 MCP 配置文件是否正确
2. 确认路径使用绝对路径 (Claude Desktop) 或正确的变量 (VS Code)
3. 重启 IDE 或 Claude Desktop
4. 查看日志输出

```bash
# 手动运行服务器测试
python adaptive_agent_mcp/server.py --storage-path ./test_memory
```

### 问题 2: Ripgrep 搜索不可用

**症状**: `search_memory_content` 返回 "ripgrep not found"

**解决方案**:

```bash
# 1. 检查是否安装
rg --version

# 2. 如果未安装，参考"安装 Ripgrep"部分

# 3. 如果已安装但未在 PATH 中，显式指定路径
# 在 MCP 配置中添加:
"args": [
  "server.py",
  "--storage-path", "./memory",
  "--ripgrep-path", "C:/Program Files/ripgrep/rg.exe"
]
```

### 问题 3: 索引不更新

**症状**: `query_memory_headers` 找不到新添加的日志

**解决方案**:

```bash
# 手动重建索引
python -c "
import sys
sys.path.append('adaptive_agent_mcp')
from src.indexer import indexer
indexer.build_index()
print('Index rebuilt!')
"
```

### 问题 4: 时间不正确

**症状**: 日志文件的日期与实际不符

**原因**: 系统时间设置错误

**解决方案**:

```bash
# Windows
w32tm /resync

# macOS/Linux
sudo ntpdate -s time.nist.gov
```

### 问题 5: 权限错误

**症状**: "Permission denied" 或 "Access denied"

**解决方案**:

```bash
# 检查目录权限
ls -la agent_memory

# 修复权限 (Linux/macOS)
chmod -R 755 agent_memory

# Windows: 右键 -> 属性 -> 安全 -> 编辑权限
```
